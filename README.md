# tyr-pages-assets

Frontend and art for TYR.pages: https://tyrpages.legomaster188.workers.dev

- `index.html`, `app.js`, `styles.css` -- the live main site, no data included
- `maps/`, `maps/minimap/`, `tanks/` -- map images and tank icons

No match or player data lives here. That's fetched at runtime from the API and
is not part of this repo.

Only what the live site actually serves belongs in here. Unreleased work stays
out, in the private repo.
